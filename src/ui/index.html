01 / About KaneFlow

Closing the gap in AI code generation.

AI coding agents can write code in seconds. But someone still has to open Chrome, click around, and test if the feature actually works. That is the bottleneck. KaneFlow bridges this gap by turning Kane CLI into an agent’s eyes and hands.

06 / FAQ

Frequently Answered Questions.

How does KaneFlow talk to Kane CLI? +
KaneFlow spawns @testmuai/kane-cli with the --agent flag. Kane CLI streams NDJSON events for every step, action, and checkpoint directly into KaneFlow's process manager via standard streams.
Do I need third-party API keys to run the self-healing demo? +
No. KaneFlow includes a built-in semantic AST repair engine that works 100% out-of-the-box with zero configuration. It also supports optional OPENAI_API_KEY, ANTHROPIC_API_KEY, or GEMINI_API_KEY for open-ended prompt repairs.
How does this differ from standard Playwright tests? +
Playwright requires developers to hand-code selectors, assertions, and timeouts. Kane CLI uses plain English and AI vision, meaning specifications are written naturally and the agent can fix both the code and the test seamlessly.
